# Projeto de Detecção de Fraude

Este projeto tem como objetivo detectar fraudes utilizando técnicas de machine learning.

## Estrutura do Projeto

- `docker/`: Configurações Docker para API, app e Redis.
- `data/`: Dados brutos, processados e externos.
- `src/`: Código fonte para processamento, modelos, monitoramento e utilitários.
- `notebooks/`: Notebooks para análise exploratória e demonstração do modelo.
- `deployment/`: Arquivos para deploy da API, app e modelos.
- `tests/`: Testes unitários e de integração.
- `config/`: Parâmetros globais.
- `docs/`: Documentação técnica.
